# Resume Keyword Extractor (AI Mini Project)

## Overview
This project extracts and analyzes keywords from resumes using NLP (Natural Language Processing).
It helps identify key skills and technologies mentioned in a resume.

##  Features
- PDF text extraction using PyPDF2
- Text cleaning and tokenization
- Keyword frequency analysis
- TF-IDF keyword weighting
- Visual representation via bar chart & word cloud

##  Tech Stack
Python, NLTK, scikit-learn, matplotlib, wordcloud, PyPDF2

##  Output
- Top keywords (by frequency)
- TF-IDF weighted keywords
- Bar chart & word cloud
- CSV and text report

## How to Run
```bash
pip install -r requirements.txt
python main.py
